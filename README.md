# Health Monitor

A simple daily health tracker to check in on water, sleep, and food.

### Why This Project Exists

I built this as a local-only tool to remind myself to take care of my basic needs. Sometimes, when I get deep into a project, I forget to drink water or sleep enough.

### How It Works

- Enter how many glasses of water you drank.
- Enter how many hours you slept.
- Log whether you ate three proper meals.
- The app saves your data in your browser's `localStorage` so it persists between visits.

### Built With

- HTML5
- CSS3 (custom background, clean layout)
- Vanilla JavaScript (DOM manipulation, `localStorage` API)
